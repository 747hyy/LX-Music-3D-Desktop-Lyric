# LX‑Music 2.12.2‑3D 歌词增强版
> ⚠️ **本版本为第三方修改定制版，非官方原版**，仅供个人学习交流使用。

本项目基于开源项目 [lx‑music‑desktop](https://github.com/lyswhut/lx‑music‑desktop) 修改，原项目采用 Apache‑2.0 协议，本衍生版本同样遵循 Apache‑2.0 开源协议。

## 📦 下载
前往 [发布](https://github.com/747hyy/-3d-/releases) 下载 `LX‑Music‑2.12.2‑3D‑x64.zip`

## ✨ 主要功能
- **桌面歌词3D旋转**：支持 X / Y / Z 三轴手动滑块调节旋转角度，不会跟随鼠标、不会自动摆动
- **角度锁定/重置**：调好角度可以锁定防止误触；一键重置恢复 0° 正面显示
- **真透明歌词背景**：默认 `#00000000` 完全透明，适合直播窗口采集
- **自定义背景**：可自选背景颜色、调节透明度，设置自动保存；一键恢复完全透明
- **完整保留原版全部歌词能力**：逐字着色、横竖排、窗口锁定等原版功能全部可用，关闭3D即回归原版效果
- **多套启动脚本适配直播采集**，专门优化抖音直播伴侣窗口采集，解决 Windows10 部分机型采集黑屏问题

### 📜 内置启动脚本
| 脚本 | 用途 |
|---|---|
| `Start‑3D.cmd` | 默认正常启动，保留硬件加速 |
| `Start‑3D‑Capture.cmd` | 直播伴侣采集模式，保留硬件加速 |
| `Start‑3D‑Capture‑Compat.cmd` | 兼容模式，关闭硬件加速，解决采集黑屏 |
| `Restore‑original.cmd` | 一键恢复回原版官方程序 |

## 🚀 安装与启动
1. 将 `LX‑Music‑2.12.2‑3D‑x64.zip` **完整解压到本地文件夹，不要直接在压缩包内运行程序**
2. 首次使用直接双击 `Start‑3D.cmd` 启动
3. Windows弹出安全提示，请确认文件为自己解压所得再允许运行
4. 配置保存在目录内 `portable\userData`，属于便携模式，无需安装

## 🎵 桌面歌词操作步骤
1. 启动程序播放歌曲，打开桌面歌词窗口
2. 鼠标移动到歌词窗口边缘，调出控制栏，开启3D功能
3. 拖动 X/Y/Z 滑块调整旋转角度
4. 调整完成点击**锁定**避免误操作；角度错乱点**重置**恢复正面
5. 不需要3D效果，直接关闭3D开关，歌词变回原版样式

## 🎨 透明与自定义背景
- 默认：歌词窗口为全透明 `#00000000`
1. 打开3D控制栏，点击取色器选择背景颜色，拖动透明度滑块
2. 设置自动保存；点击【透明】按钮恢复完全透明
> 提示：选择颜色后如果透明度为0看不到效果，程序会自动上调一点透明度；想要彻底透明请点「透明」按钮。

## 🎥 抖音直播伴侣窗口采集教程
1. 使用 `Start‑3D‑Capture.cmd` 启动程序
2. 直播伴侣添加 **窗口采集**，选择LX‑Music桌面歌词窗口（不要选整个桌面）
3. 关闭伴侣内黑底兼容、色键抠色等选项
4. 预览画面全黑：退出软件，改用 `Start‑3D‑Capture‑Compat.cmd` 兼容模式，重新添加采集窗口

> 注意：透明能否被采集保留Alpha通道，取决于Windows图形合成与采集软件。如果采集软件把透明渲染为黑色，程序无法恢复丢失的透明信息，可以尝试显示器采集、区域采集备选方案。

## 🛠 Windows10 黑屏问题处理
现象：歌词桌面显示正常，但直播采集预览画面全黑
1. 完全退出LX‑Music与直播伴侣
2. 使用 `Start‑3D‑Capture‑Compat.cmd` 启动（关闭硬件加速，动画性能会略微下降）
3. 直播伴侣重新添加窗口采集
4. 依旧异常：尝试显示器/区域采集；更新显卡驱动，检查系统缩放设置。

## ↩️ 恢复原版
完全退出LX‑Music后，运行 `Restore‑original.cmd`，即可还原官方原版 `app.asar`。

## ❓ 常见问题
**Q：桌面歌词看着是黑色背景？**
> 程序默认是真透明。黑色一般来自采集软件/系统合成把透明填充黑色，请直接看桌面的歌词窗口，区分是程序本身还是采集端问题。

**Q：选了背景颜色看不到效果？**
> 透明度为0时完全看不见颜色；选色后程序会自动调高一点透明度，也可以手动拖动透明度滑块；点「透明」回到全透明。

**Q：3D歌词会跟随鼠标自动旋转吗？**
> 不会，仅通过X/Y/Z滑块手动调整，无自动摆动、跟随鼠标效果。

**Q：角度调乱了怎么办？**
> 点重置按钮，三轴角度归零，同时解除锁定。

## ⚠️ 使用建议
